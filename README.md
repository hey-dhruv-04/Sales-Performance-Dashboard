# Sales Performance Dashboard

## Overview

An interactive Sales Performance Dashboard built using Microsoft Power BI to analyze sales performance across different years, product categories, territories, and products.

## Dashboard

![Sales Dashboard](Sales%20Dashboard.png)

## Key Metrics

- Total Revenue: ₹123,216,786
- Total Orders: 31,465
- Total Customers: 19,119
- Average Order Value: ₹3,916

## Analysis

The dashboard provides insights into:

- Revenue by year
- Revenue by product category
- Revenue by territory
- Top 10 products by revenue
- Monthly revenue trends

## Tools Used

- Microsoft Power BI
- DAX
- Power Query
- AdventureWorks dataset
